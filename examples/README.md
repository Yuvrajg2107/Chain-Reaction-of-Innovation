# Synthetic contract examples

`synthetic-domain-pack.json` is an invented thermal-layer fixture for understanding the schema. It includes all six entity types, parameter declarations, a structural relationship, model slots, configuration bindings, and forward/backward scenario forms.

Its model and evidence are intentionally unreviewed. Every scenario expects `unresolved`; the future engine must not treat a numeric input set as permission to execute an unapproved engineering model. The arithmetic illustration in the reasoning specification explains possible behavior after real review, without claiming an experiment.

This fixture is not a collected dataset, approved material record, validated product, application implementation, or benchmark result.
